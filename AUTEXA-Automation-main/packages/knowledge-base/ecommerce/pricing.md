# Global E-commerce Pricing Policies

Summary of shipping and fee structures:

## Shipping Tiers
- **Standard (3-5 days)**: $4.99 (Free on orders > $50)
- **Expedited (2 days)**: $12.99
- **Overnight (Next day)**: $24.99

## Return Fees
- **Within 30 Days**: $0 (Free return shipping labels)
- **After 30 Days**: Rejections apply, exchanges only.
