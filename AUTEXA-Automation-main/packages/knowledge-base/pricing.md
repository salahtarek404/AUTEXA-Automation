# Autexa AI Automation Pricing & Packages

We offer flexible subscription plans tailored to the size and volume of your business. Below are our standard packages.

## Subscription Tiers

### 1. Starter Package
- **Best For**: Small businesses looking to automate a single channel (e.g., website widget).
- **Includes**: 1 active channel, basic RAG knowledge base, up to 1,000 messages/month.
- **Estimated Monthly Cost**: $150 - $300/month (rough range, subject to usage limits).

### 2. Growth Package
- **Best For**: Mid-sized businesses automating multiple channels (e.g., website + WhatsApp).
- **Includes**: Up to 3 active channels, advanced RAG with auto-updating knowledge base, up to 5,000 messages/month, custom lead qualification metrics.
- **Estimated Monthly Cost**: $400 - $800/month (rough range).

### 3. Enterprise Package
- **Best For**: High-volume operations requiring dedicated support and custom API integrations.
- **Includes**: Unlimited channels, custom CRM sync (Salesforce/Hubspot), dedicated LLM deployment, custom analytics dashboard, priority SLA.
- **Estimated Monthly Cost**: Starting from $1,200/month (rough estimate, scoped individually).

## Additional Costs
- **Meta API Costs (for WhatsApp)**: Charged directly by Meta per user-initiated or business-initiated conversation template.
- **Extra Usage**: Billed at approximately $0.05 - $0.10 per extra message turn.

*Disclaimer: All pricing ranges listed here are rough estimations. Final billing is dependent on exact message volume, integration complexity, and support level agreements.*
